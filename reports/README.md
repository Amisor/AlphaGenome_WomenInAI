# Clinical Reports & Decision Support Dashboards

This directory contains standalone, zero-dependency HTML clinical decision reports generated by the AlphaGenome × SpliceVarDB pipeline for **Sarah Jenkins** (39-year-old female, HBOC-30 multigene panel).

Each HTML report is completely self-contained (inline styles, inline SVG signal tracks, zero external CDN scripts) and works directly when opened in any modern web browser (`file://` protocol supported, $0 external API cost).

## Features Built Into Every Report

1. **Option A Side-by-Side Split View**:
   - **Left Panel (62%)**: Clinical findings, genomic coordinates, biological mechanism, SVG splicing signal diagrams, calibrated risk thermometer, ACMG/AMP criteria (PVS1, PS3/BS3, PP3/BP4), and prioritized peer-reviewed literature.
   - **Right Panel (38%)**: Live, embedded **Clinical AI Assistant** powered by a client-side JavaScript reasoning engine with quick-prompt chips for instant clinical guidance.
2. **Warm Off-White Editorial Aesthetic**:
   - Institutional typography, soft alabaster backdrop (`#faf8f5`), crisp stone cards, and zero informal emojis.
3. **1-Click Copy Tumor Board Note**:
   - Formatted molecular tumor board summary ready for instant insertion into hospital EHR/EMR charts, complete with floating toast notifications.
